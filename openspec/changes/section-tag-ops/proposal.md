# セクションとタグそのものの操作、マイタスクのセクション (Issue #33, #35)

振る舞いを変える変更。

## なぜ

セクションは名前を変えられるだけで、作る・消す・並べ替えるができない。タグは作る・付ける・外すだけで、名前や色を変えたり、消したりできない。プロジェクトを整理するたびに Web に戻ることになる (#33)。

## 何を変えるか

- outbox の種類を足す: `create_section`、`delete_section`、`insert_section` (並べ替え)、`update_tag` (名前と色)、`delete_tag`。どれもオフラインで積める。
- セクションの作成はローカル gid を付け、すぐにタスクを移せる。作成が送れたら、キャッシュ (セクション、タスクの所属) と outbox (`task_gid`、payload・base の中のローカル gid) を本物の gid に書き換え、`sync_state` に `section:<local>` → 本物 を記録する。作成が届いたか分からないときは、送る前に記録した「同じ名前の既存のセクション」以外で同じ名前のものを Asana で探して照合する。
- ローカル gid のセクションを名指しする操作 (タスクの移動、並べ替え、名前の変更、削除) は、作成が outbox にある間は待つ。作成を取り消すと、そこへの移動は元に戻り、そこへ作ったタスクはセクションなしで残る。
- 削除は空のセクションだけ、最後のセクションは消さない (Asana と同じ)。Asana で既に消えていれば完了とする。タグの削除はすべてのタスクから外す。取り消せば元に戻す。
- 送っていない変更は、同期で Asana の値を入れても保つ (作ったセクションは残り、消したものは消えたまま、並べ替えはやり直し、タグの名前・色は新しいまま)。
- Asana が 402 (プランにない機能) を返したら、その機能 (セクションの作成・削除・並べ替え / タグの変更・削除) を記録し、TUI のメニュー、MCP のツール、CLI のコマンド (エラー) から出さない。
- TUI: プロジェクトのリストとボードで、カーソルのあるセクションに対して、追加 (`n`)・上へ (`K`)・下へ (`J`)・削除 (`O`、確認あり) をスペースメニューに出す。空のセクションも見出しとして出し、選べる。タグは `y` で選んで、名前・色の変更と削除 (確認あり)。
- CLI: `section create/rm/move`、`tag rename/color/rm`。`rm` は `--yes` がないと何もせずエラーにする (`--dry-run` は `--yes` なしで計画を出す)。
- MCP: `create_section`、`move_section`、`delete_section`、`update_tag`、`delete_tag`。
- マイグレーション 1 つ: `tags.color`、`tasks.assignee_section_gid`、`my_task_sections`。

## やらないこと

- セクションの作成を、プロジェクトの作成 (オンライン) と一緒にはしない。
- タグの作成時に色は付けない (名前で作り、色はあとで変える)。
- 同期で Asana から消えたタグをキャッシュから消すことはしない (今と同じ)。
