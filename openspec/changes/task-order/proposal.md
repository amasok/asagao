# タスクの並びを Asana の順で持つ (Issue #51)

振る舞いを足す変更。

## なぜ

キャッシュがタスクの並び順を持っていない。セクションの中のタスクは完了・期日・名前の順、サブタスクは作った順 (TUI の展開は期日・名前の順) で並び、Asana の並びと食い違う。`task move --before/--after` や `set_parent` の位置で並べ替えても、キャッシュの一覧には出ない。

## 何を変えるか

- store: `task_memberships.position` (セクションの中の位置) と `tasks.subtask_position` (親の中の位置) を足す (マイグレーション 24)。NULL は「分からない」。分からないタスクは、分かるタスクのあとに、今までの順で並ぶ。
- 取り込み: プロジェクトを全部取ったとき (`GET /tasks?project=` を modified_since なしで) は、返った順をそのまま位置にする。Events や modified_since で一部のタスクだけ取ったときは、そのタスクが入っているセクションを `GET /sections/{gid}/tasks` (gid だけ) で取り直す。完了済みをあとから取ったとき (#54) も同じ。サブタスクは `GET /tasks/{gid}/subtasks` の順を位置にし、Events がサブタスクを挙げたら、その親のサブタスクを取り直す。
- 並べ方: `ListTasks` は、セクション・プロジェクトで絞ったときはセクションの順、その中は位置の順。親で絞ったときと `GetTask` のサブタスクは位置の順。どれも、位置の分からないタスクは今までの順であとに置く。
- 積んだとき: `move_task` と `set_parent` は、Asana が置く場所にキャッシュでもすぐ置く。位置なしで別のセクションへ移すと先頭 (addTask と同じ)、位置なしで親を変えると末尾 (分からない扱い)。送るまでは、並びの取り直しやタスクの取り込みがあっても、積んだ場所に戻す。元の場所に戻したときや取り消したときは、元の位置に戻す。
- 文書: README・CLI のヘルプ・MCP の説明から「並び順は Asana にだけ反映」をなくす。

## やらないこと

- マイタスクの並び (今までどおり期日の区分ごと)。
- 既存のキャッシュの並びをすぐに取ること。毎日の全件同期で入るまでは、今までの順で並ぶ。
- TUI でのセクション内の並べ替えの操作。
