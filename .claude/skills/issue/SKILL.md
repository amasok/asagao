# issue

1. 重複を確かめます: `gh issue list --state open --search "<キーワード>" --limit 5`。同じものがあれば、`gh issue comment` で追記して終わります。
2. 作ります。タイトルは日本語で、症状が分かる一文にします。本文はヒアドキュメントで渡します。

```sh
gh issue create --title "<症状が分かる一文>" --body "$(cat <<'EOF'
## 何が起きるか
<どういう入力・操作で、何が起きるか。main でも起きるかどうか>

## 影響
<データが消えるか / 見た目だけか / 安全性に関わるか>

## 直し方の案
<分かっていれば。場所は `path/file.go` の関数名で書く>

## 見つけた経緯
<どの作業・どのテストで見つけたか (1 行)>

🤖 Generated with [Claude Code](https://claude.com/claude-code)
EOF
)"
```

3. 複数あるときは、関係の近いものは 1 つにまとめます。ユーザーには、番号とタイトルだけを返します。
4. ユーザーの名前やメールアドレスなど、個人の情報は本文に書きません。
